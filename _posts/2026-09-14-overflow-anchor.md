[caniuse](https://caniuse.com/?search=overflow-anchor) · [mdn](https://developer.mozilla.org/en-US/search?q=overflow-anchor) · [spec](https://drafts.csswg.org/css-scroll-anchoring-1/#exclusion-api)

The `overflow-anchor` CSS property sets an element as a possible scroll anchor, reducing unintended scrolling when document changes occur above the current scrollport. This is enabled by default where supported.

- ``css.properties.overflow-anchor`` [[mdn]](https://developer.mozilla.org/en-US/search?q=css.properties.overflow-anchor)
